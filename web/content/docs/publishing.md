# Publishing to the feed

Put a session in the public feed so people can find it. You need to own the session.

## Publish a session

Use **Publish** on the session page. Publishing makes the session public and lists it in the public feed and in feed search (by title and tag).

Use **Unpublish** to take it out of the feed. This also sets the session back to private; invited people keep their access. See [Sharing & visibility](/docs/sharing).

## Before you publish

Everything the agent did is visible in the session: prompts, commands, file paths and diffs. Check the replay for secrets, tokens, internal hostnames and private paths first.

## Write it up as a story

A session's story page (`/story/<id>`) presents the session as a readable write-up you can link to.
