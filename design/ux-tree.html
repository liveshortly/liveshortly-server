00 User Types & Entry Points Who uses LiveShortly and how they arrive
👤
User Type · Unauthenticated
Anonymous Visitor
Arrives via search, social link, or direct URL. Can browse and watch sessions without logging in. Cannot comment.
#discover #watch #no-auth
🔗
User Type · Unauthenticated
Shared Link Visitor
Receives a direct session link from a developer. Lands directly on Session Viewer. Can watch; must sign in to comment if commenter access is granted.
#shared-link #direct
💻
User Type · Authenticated
Developer / Streamer
Signed in with Google. Runs Claude Code with hooks installed. Owns sessions. Can share, end, make public, and inject comments from CLI.
#owner #cli #stream
👁️
User Type · Authenticated
Viewer / Commenter
Signed in. Access granted via share (viewer or commenter role). Can watch replays of ended sessions and comment on sessions with commenter access.
#viewer #commenter #shared
🤖
User Type · Non-Human
CLI Hook / System
Python hooks fired by Claude Code events. Posts session events via Bearer JWT. Drains viewer comments to inject into Claude context.
#api #bearer #automated

05 Session State Machine All states a session can be in and how it transitions
● LIVE
Active Claude Code session. Events streaming via SSE. CLI hooks posting events in real time.
stop.py fires → ENDED
Owner clicks ⊘ End → ENDED
Owner shares link → LIVE + SHARED
Owner makes public → LIVE + PUBLIC
◼ ENDED
Session completed. Full event log available for replay. No new events. Redis buffer archived to storage.
Owner shares link → ENDED + SHARED
Owner makes public → ENDED + PUBLIC
Revoke all shares → ENDED (private)
🔗 SHARED
Session has explicit share grants. Specific users have viewer or commenter access.
Visibility = link → LINK-ONLY
Visibility = public → PUBLIC
All shares revoked → PRIVATE
🔒 PRIVATE
Default state. Only the owner can access. Not visible to anyone else.
⊕ Share added → SHARED
● Make Public → PUBLIC
🌐 PUBLIC
Visible to all users, including unauthenticated. Appears in public feed on Landing Page.
Owner reverts → PRIVATE
link_role=commenter → PUBLIC + anyone can comment
🔗 LINK-ONLY
Accessible to anyone with the exact URL. Not discoverable in public feed. Requires the link.
Owner makes public → PUBLIC
Owner locks down → PRIVATE
