Version 3 — Core Screens

Five HTML mockups for the core user-facing screens, each with a live ◐ theme toggle in the top bar. Light mode is the current shipped app, unchanged — same tokens as web/app/globals.css, same square hairline-border terminal-HUD language. Dark mode is new, drawing its shell (persistent library sidebar, hero cover art, tracklist rows, bottom status dock, rounded pill controls) from a Spotify-style reference, re-skinned onto LiveShortly's actual sessions/events/watchers domain.
