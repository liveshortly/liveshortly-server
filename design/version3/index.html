Version 3 — Core Screens

HTML mockups for the core user-facing screens, each with a live ◐ theme toggle in the top bar. Light mode is the current shipped app, unchanged — same tokens as web/app/globals.css, same square hairline-border terminal-HUD language. Dark mode uses the real app's actual dark tokens — same shapes, only colors differ. Every screen also has a dedicated Mobile variant, framed at iPhone 13 (390×844) with real safe-area insets and PWA meta tags (apple-mobile-web-app-capable, viewport-fit=cover) so it feels like an installed app when opened full-screen on a phone — persistent bottom tab bar, slide-in drawers, and bottom action sheets in place of the desktop sidebar/menus.
