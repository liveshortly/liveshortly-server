Design pitch · broadcast identity · iteration 2

A streamer's setup, for someone whose "game" is a codebase

Same palette, same philosophy, rebalanced composition. Iteration 1 made the code editor the main stage — wrong instinct: nobody can read a diff through YouTube's compression at a glance, and reading code isn't why anyone watches this. The two things that actually are the show — the chat where viewers talk back, and the tool calls that prove the agent is really doing something — now get the space that the code editor was taking.
