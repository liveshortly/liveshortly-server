C The "honest placeholder" pattern components/preview.tsx — used by Profile, Replay, Story, Compose
✓ Real, wired to the API
Session data, event log, own-session lists, activity dates
Anything backed by getSession / listSessions / me() renders live values — never fabricated.
◐ PreviewBanner + PlaceholderNote
AI summaries, language DNA, replay scrubber/chapters, blog persistence
No backend exists yet. Rather than fake data, these panels render an explicit amber "PREVIEW" ribbon and a "coming soon" note — the layout is real, the content is not.

Four screens share this contract: PageHead, PanelBox, Stat, PreviewBanner, PlaceholderNote. It's the cleanest reuse boundary in the component tree — worth keeping as the template for the next preview screen rather than inventing a new placeholder style.
